## What It Is

Go is a statically typed, compiled programming language designed at Google by Robert Griesemer, Rob Pike, and Ken Thompson. Released in 2009, Go was created to address shortcomings in other languages used at Google—particularly around compilation speed, dependency management, and concurrent programming.

Go is known for:
- **Simplicity**: Small language, easy to learn
- **Fast compilation**: Large projects compile in seconds
- **Built-in concurrency**: Goroutines and channels
- **Strong standard library**: HTTP, JSON, crypto, testing built-in
- **Single binary deployment**: No runtime dependencies
- **Garbage collection**: Memory-safe without manual management

Go powers major infrastructure: Docker, Kubernetes, Terraform, Prometheus, and many microservices at companies like Google, Uber, Dropbox, and Twitch.

## Go vs JavaScript/TypeScript

| Aspect | Go | JavaScript/TypeScript |
|--------|----|-----------------------|
| Typing | Static, compiled | Dynamic (JS) / Static (TS) |
| Concurrency | Goroutines, channels | Event loop, async/await |
| Error handling | Explicit returns | Exceptions |
| Memory | Garbage collected | Garbage collected |
| Deployment | Single binary | Node.js runtime |
| Package management | Go modules | npm |
| Speed | Very fast | Slower (interpreted) |

### Arrays and Slices

```go
package main

import "fmt"

func main() {
    // Arrays (fixed size)
    var arr [5]int                    // [0 0 0 0 0]
    arr2 := [3]int{1, 2, 3}           // [1 2 3]
    arr3 := [...]int{1, 2, 3, 4, 5}   // Size inferred
    
    // Slices (dynamic, backed by arrays)
    var slice []int                   // nil slice
    slice2 := []int{1, 2, 3}          // [1 2 3]
    slice3 := make([]int, 5)          // [0 0 0 0 0] length 5
    slice4 := make([]int, 0, 10)      // length 0, capacity 10
    
    // Slice operations
    nums := []int{1, 2, 3, 4, 5}
    fmt.Println(nums[1:3])   // [2 3]
    fmt.Println(nums[:3])    // [1 2 3]
    fmt.Println(nums[2:])    // [3 4 5]
    fmt.Println(len(nums))   // 5
    fmt.Println(cap(nums))   // 5
    
    // Append
    nums = append(nums, 6)           // [1 2 3 4 5 6]
    nums = append(nums, 7, 8, 9)     // [1 2 3 4 5 6 7 8 9]
    
    // Copy
    src := []int{1, 2, 3}
    dst := make([]int, len(src))
    copy(dst, src)
    
    // Iterate
    for i, v := range nums {
        fmt.Printf("Index: %d, Value: %d\n", i, v)
    }
    
    // Just values
    for _, v := range nums {
        fmt.Println(v)
    }
}
```

### Basic Functions

```go
package main

import "fmt"

// Basic function
func greet(name string) string {
    return "Hello, " + name
}

// Multiple parameters same type
func add(a, b int) int {
    return a + b
}

// Multiple return values
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("cannot divide by zero")
    }
    return a / b, nil
}

// Named return values
func rectangle(width, height float64) (area, perimeter float64) {
    area = width * height
    perimeter = 2 * (width + height)
    return  // Returns named values
}

// Variadic function
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

func main() {
    fmt.Println(greet("Steve"))
    
    result, err := divide(10, 2)
    if err != nil {
        fmt.Println("Error:", err)
    } else {
        fmt.Println("Result:", result)
    }
    
    fmt.Println(sum(1, 2, 3, 4, 5))
    
    // Spread slice
    nums := []int{1, 2, 3}
    fmt.Println(sum(nums...))
}
```

### First-Class Functions

```go
package main

import "fmt"

func main() {
    // Function as variable
    add := func(a, b int) int {
        return a + b
    }
    fmt.Println(add(2, 3))
    
    // Function as parameter
    apply := func(fn func(int, int) int, a, b int) int {
        return fn(a, b)
    }
    fmt.Println(apply(add, 5, 3))
    
    // Closure
    counter := func() func() int {
        count := 0
        return func() int {
            count++
            return count
        }
    }
    
    c := counter()
    fmt.Println(c())  // 1
    fmt.Println(c())  // 2
    fmt.Println(c())  // 3
}
```

## Interfaces

```go
package main

import (
    "fmt"
    "math"
)

// Define interface
type Shape interface {
    Area() float64
    Perimeter() float64
}

// Circle implements Shape
type Circle struct {
    Radius float64
}

func (c Circle) Area() float64 {
    return math.Pi * c.Radius * c.Radius
}

func (c Circle) Perimeter() float64 {
    return 2 * math.Pi * c.Radius
}

// Rectangle implements Shape
type Rectangle struct {
    Width, Height float64
}

func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

func (r Rectangle) Perimeter() float64 {
    return 2 * (r.Width + r.Height)
}

// Function accepting interface
func PrintShape(s Shape) {
    fmt.Printf("Area: %.2f, Perimeter: %.2f\n", s.Area(), s.Perimeter())
}

// Empty interface (any type)
func PrintAny(v interface{}) {
    fmt.Println(v)
}

// Type assertion
func describe(i interface{}) {
    switch v := i.(type) {
    case int:
        fmt.Println("Integer:", v)
    case string:
        fmt.Println("String:", v)
    default:
        fmt.Println("Unknown type")
    }
}

func main() {
    c := Circle{Radius: 5}
    r := Rectangle{Width: 3, Height: 4}
    
    PrintShape(c)
    PrintShape(r)
    
    // Type assertion
    var s Shape = Circle{Radius: 3}
    circle, ok := s.(Circle)
    if ok {
        fmt.Println("Radius:", circle.Radius)
    }
}
```

## Error Handling

```go
package main

import (
    "errors"
    "fmt"
)

// Return error
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}

// Custom error type
type ValidationError struct {
    Field   string
    Message string
}

func (e *ValidationError) Error() string {
    return fmt.Sprintf("%s: %s", e.Field, e.Message)
}

func validateUser(name string) error {
    if name == "" {
        return &ValidationError{
            Field:   "name",
            Message: "cannot be empty",
        }
    }
    return nil
}

// Error wrapping (Go 1.13+)
func processFile(filename string) error {
    err := readFile(filename)
    if err != nil {
        return fmt.Errorf("processing %s: %w", filename, err)
    }
    return nil
}

func main() {
    // Basic error handling
    result, err := divide(10, 0)
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    fmt.Println("Result:", result)
    
    // Type assertion for custom errors
    err = validateUser("")
    if err != nil {
        if ve, ok := err.(*ValidationError); ok {
            fmt.Printf("Validation failed on %s: %s\n", ve.Field, ve.Message)
        }
    }
    
    // Check wrapped errors
    err = processFile("test.txt")
    if errors.Is(err, os.ErrNotExist) {
        fmt.Println("File not found")
    }
}
```

### Goroutines

import (

### Channels

```go
package main

import "fmt"

func main() {
    // Unbuffered channel
    ch := make(chan int)
    
    // Send in goroutine
    go func() {
        ch <- 42  // Blocks until received
    }()
    
    // Receive
    value := <-ch  // Blocks until sent
    fmt.Println(value)
    
    // Buffered channel
    buffered := make(chan int, 3)
    buffered <- 1
    buffered <- 2
    buffered <- 3
    // buffered <- 4  // Would block (buffer full)
    
    fmt.Println(<-buffered)  // 1
    
    // Close channel
    close(buffered)
    
    // Range over channel
    ch2 := make(chan int)
    go func() {
        for i := 0; i < 5; i++ {
            ch2 <- i
        }
        close(ch2)
    }()
    
    for v := range ch2 {
        fmt.Println(v)
    }
    
    // Select (like switch for channels)
    ch3 := make(chan string)
    ch4 := make(chan string)
    
    go func() { ch3 <- "one" }()
    go func() { ch4 <- "two" }()
    
    for i := 0; i < 2; i++ {
        select {
        case msg := <-ch3:
            fmt.Println("From ch3:", msg)
        case msg := <-ch4:
            fmt.Println("From ch4:", msg)
        }
    }
}
```

### WaitGroup and Mutex

```go
package main

import (
    "fmt"
    "sync"
)

func main() {
    // WaitGroup - wait for goroutines to finish
    var wg sync.WaitGroup
    
    for i := 0; i < 5; i++ {
        wg.Add(1)
        go func(n int) {
            defer wg.Done()
            fmt.Println("Goroutine", n)
        }(i)
    }
    
    wg.Wait()
    fmt.Println("All done")
    
    // Mutex - protect shared data
    var mu sync.Mutex
    counter := 0
    
    for i := 0; i < 1000; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            mu.Lock()
            counter++
            mu.Unlock()
        }()
    }
    
    wg.Wait()
    fmt.Println("Counter:", counter)
}
```

### Worker Pool Pattern

```go
package main

import (
    "fmt"
    "sync"
)

func worker(id int, jobs <-chan int, results chan<- int, wg *sync.WaitGroup) {
    defer wg.Done()
    for job := range jobs {
        fmt.Printf("Worker %d processing job %d\n", id, job)
        results <- job * 2
    }
}

func main() {
    jobs := make(chan int, 100)
    results := make(chan int, 100)
    var wg sync.WaitGroup
    
    // Start 3 workers
    for w := 1; w <= 3; w++ {
        wg.Add(1)
        go worker(w, jobs, results, &wg)
    }
    
    // Send jobs
    for j := 1; j <= 9; j++ {
        jobs <- j
    }
    close(jobs)
    
    // Wait for workers
    wg.Wait()
    close(results)
    
    // Collect results
    for result := range results {
        fmt.Println("Result:", result)
    }
}
```

## HTTP Server

```go
package main

import (
    "encoding/json"
    "fmt"
    "log"
    "net/http"
)

type User struct {
    ID   int    `json:"id"`
    Name string `json:"name"`
}

var users = []User{
    {ID: 1, Name: "Steve"},
    {ID: 2, Name: "Alice"},
}

func getUsers(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(users)
}

func createUser(w http.ResponseWriter, r *http.Request) {
    var user User
    if err := json.NewDecoder(r.Body).Decode(&user); err != nil {
        http.Error(w, err.Error(), http.StatusBadRequest)
        return
    }
    
    user.ID = len(users) + 1
    users = append(users, user)
    
    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(http.StatusCreated)
    json.NewEncoder(w).Encode(user)
}

func main() {
    http.HandleFunc("/users", func(w http.ResponseWriter, r *http.Request) {
        switch r.Method {
        case "GET":
            getUsers(w, r)
        case "POST":
            createUser(w, r)
        default:
            http.Error(w, "Method not allowed", http.StatusMethodNotAllowed)
        }
    })
    
    fmt.Println("Server running on :8080")
    log.Fatal(http.ListenAndServe(":8080", nil))
}
```

## Interview Questions

**Q: What is Go and why would you use it?**

A: Go is a statically typed, compiled language designed for simplicity and efficiency. Use it for: microservices (fast, small binaries), CLI tools, infrastructure (Docker, K8s written in Go), concurrent systems (goroutines are lightweight), and when you need fast compilation and deployment. It excels at network services and systems programming.

**Q: Explain goroutines vs threads.**

A: Goroutines are lightweight threads managed by the Go runtime, not the OS. They start with ~2KB stack (vs ~1MB for threads), are multiplexed onto OS threads by the scheduler, and communicate via channels (CSP model) rather than shared memory. You can run millions of goroutines; threads are limited to thousands. Creation and context switching is much cheaper.

**Q: How do channels work?**

A: Channels are typed conduits for communication between goroutines. Unbuffered channels block sender until receiver is ready (synchronous). Buffered channels block only when full. Use `make(chan Type)` or `make(chan Type, capacity)`. Send with `ch <- value`, receive with `value := <-ch`. Close with `close(ch)`. Use `select` for non-blocking operations on multiple channels.

**Q: Explain Go's error handling philosophy.**

A: Go uses explicit error returns instead of exceptions. Functions that can fail return an error as the last value: `result, err := doSomething()`. Check errors immediately: `if err != nil { return err }`. This makes error handling visible and forces developers to consider failure cases. Custom errors implement the `Error() string` method. Wrap errors with `fmt.Errorf("context: %w", err)`.

**Q: What's the difference between value and pointer receivers?**

A: Value receivers operate on a copy of the struct—modifications don't affect the original. Pointer receivers operate on the original struct—can modify it, and avoid copying large structs. Use pointer receivers when: modifying the receiver, struct is large, or consistency (if one method needs pointer, use pointers for all). Value receivers are safer for read-only methods.

**Q: How does Go implement interfaces?**

A: Go uses implicit interface implementation—no `implements` keyword. A type implements an interface by implementing all its methods. This enables duck typing with compile-time checks. Empty interface `interface{}` (or `any` in Go 1.18+) accepts any type. Type assertions `v.(Type)` and type switches check concrete types at runtime.
